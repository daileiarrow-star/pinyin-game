# assets 放什么

把下面这个文件放到本目录：

## qrcode.png —— 你的收款码

- 微信收款码 / 支付宝收款码都可以
- 建议方形、边长 500px 以上、白底
- 名字必须是 `qrcode.png`（想用别的格式或文件名，改 `js/data.js` 里的 `CONFIG.qrImage`）

**没有放这个文件也不会报错**：页面会自动显示一个虚线占位框，提示"在这里放你的收款码"。

## 为什么用「扫码 + 手动发激活码」而不是在线支付？

- 个人开发者接微信支付需要企业资质，门槛高、审核慢
- 扫码收款 + 发激活码，**今天就能开始卖**，零资质要求
- 用户量起来、验证了需求之后，再换成正式支付渠道也不迟

## 更省事的分发方式

如果你已经收到了某位家长的钱，可以直接把带参数的链接发给他：

```
https://你的域名.vercel.app/?code=你的激活码
```

家长打开这个链接，页面会自动变成完整版，不用再手动输入激活码。
