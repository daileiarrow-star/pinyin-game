# 拼音小达人 · 一年级易错拼音强化练习

一个**纯静态 H5 网页**（微信里发链接就能玩），面向已学过拼音、但掌握不牢、有高频易错点的一年级小朋友。

- **零 Token 成本**：题目、讲解全部预置；语音是提前生成好的 mp3，运行时**不调用任何 AI API**
- **即时纠错闭环**：答错 → 弹出**图文讲解**（示意图 + 口诀 + 例词对比 + 易错提醒）→ 举一反三 → 原题重测
- **题目全部是最小对立对**：4 个选项 = 2 个易混音 × 2 个易混调，没法靠排除法蒙
- **6 种题型轮换**：选择 / 听音辨音 / 判断对错 / 连线配对 / 填空（补声母+补韵母）/ 拼读积木
- **男女角色 + 全身像换装**：首次进入选小男孩 / 小女孩（插画风），初始穿白 T 恤短裤，
  **79 件装备 × 13 个部位**（帽子/眼镜/耳饰/项链/手表/上衣/披风/裤裙/鞋/背包/手持/宠物/载具），
  穿上立刻出现在全身像上
- **彩蛋开箱**：先出现一颗蛋 → 点击 → 摇晃 + 音效 + 彩带 → 揭晓奖品（WebAudio 合成音效，零素材）
- **无需审核、无需服务器**：上传到 GitHub，用 Vercel 免费托管即可上线

## 二、上传到 GitHub

### 第 1 步：先设好你的 Git 身份（只需一次）

在本项目文件夹里打开终端（文件夹地址栏输入 `cmd` 回车即可），执行：

```bash
git config user.name "你的GitHub用户名"
git config user.email "你的GitHub注册邮箱"
```

> 因为本地的 git 仓库和全部文件**已经提交好了**，你只需要换个身份信息，然后推送。

### 第 2 步：在 GitHub 上建一个空仓库

1. 打开 https://github.com/new
2. **Repository name** 填 `pinyin-game`
3. 选 **Public**（Private 也能部署到 Vercel 免费版，Public 最省事）
4. **不要**勾选 "Add a README file"、".gitignore"、"license" —— 保持完全空白
5. 点 **Create repository**

### 第 3 步：把本地项目推上去

创建完成后 GitHub 会显示一个以 `git remote add origin ...` 开头的命令块。
复制那行 `git remote add origin` 的地址（形如 `https://github.com/你的用户名/pinyin-game.git`），然后执行：

```bash
git remote add origin https://github.com/你的用户名/pinyin-game.git
git push -u origin main
```

推送时会弹出一个浏览器窗口让你登录 GitHub 授权（本机已装 Git Credential Manager，跟着点就行）。
如果它改成要你输入用户名/密码：**密码位置要填 Personal Access Token**，不是登录密码。
生成方式：GitHub 右上角头像 → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token → 勾选 `repo` → 生成后复制那串字符当密码用。

> 推送成功后刷新 GitHub 页面，应该能看到 269 个文件（含 261 个语音文件）。

## 三、用 Vercel 部署上线

1. 打开 https://vercel.com/new
2. 用 GitHub 账号登录（如果还没登录）
3. 在 **Import Git Repository** 列表里找到 `pinyin-game`，点 **Import**
4. 配置页什么都不用改：
   - Framework Preset：**Other**
   - Build Command：**留空**
   - Output Directory：**留空**
5. 点 **Deploy**，等 30~60 秒

完成后 Vercel 会给你一个正式网址，形如：

```
https://pinyin-game-xxxx.vercel.app
```

**这就是可以发给家长群的链接了。** 手机微信里直接打开就能玩。

> 以后你在 GitHub 上改了任何文件，Vercel 会自动重新部署，不用再手动操作。

### 想要自己的域名？（可选）

2. Vercel 项目 → **Settings** → **Domains** → 填入你的域名 → Add
3. 按 Vercel 提示到域名服务商那里加两条 DNS 记录（一般是一条 A 记录 + 一条 CNAME）

> ⚠️ 国内域名解析到 Vercel 后，微信内打开的速度取决于网络环境。如果发现加载慢，

## 五、以后怎么改内容

知识点 / 讲解 / 装扮在 `js/data.js`，题目在 `js/questions.js`，图解在 `js/illus.js`，
全身像装备在 `js/avatar.js`。改完存盘、推到 GitHub，Vercel 自动重新部署。

### 加一道题

在 `js/questions.js` 的 `RAW_QUESTIONS` 里按格式加一行即可：

```js
['b_p','爸',['bà','pà','bá','pá'],0,'b 不送气，爸读 bà'],
```

五个位置依次是：

1. 知识点 id（必须是 `KNOWLEDGE_POINTS` 里已有的 id）
2. 题面，1~3 个汉字（轻声 / 变调那几组用的是词语）
3. 4 个选项 —— **必须是「同一个音节的易混变体」**：2 个易混音 × 2 个易混调，
   不要放一眼就假的选项，否则就失去练习意义了
4. 正确项下标（从 0 开始；前端会自动打乱顺序）
5. 一句话说明，答对后显示在反馈里

题目 id 会自动生成（`知识点id-序号`），不用手写。

**其他题型不用手写，会自动派生**：给某个知识点加够选择题后，
听音题、判断题、连线题自动生成；填空和拼读积木在 `RAW_FILL` / `RAW_SPELL` 里手写
（这两类要精挑空位和干扰块，自动派生质量不够好）。
改完跑 `node tools/check-data.js`，它会告诉你派生结果和缺什么。

### 改讲解

在 `js/data.js` 的 `EXPLANATIONS` 里改。每条讲解有 5 个内容字段：

- `illus`：示意图配置（交给 `js/illus.js` 渲染，类型有 mouth / profile / air / tone / mark / build）
- `one`：一句话核心
- `key`：口诀
- `pairs`：例词对比（至少 2 组，`[['好','hǎo'],['后','hòu']]`）
- `warn`：最常见的那个错误

`explainSpeech()` 会把这五块自动串成朗读稿，语音脚本也用同一份，不会出现"屏幕上和读的不一样"。

### 改完记得自检

```bash

# 2) 拼音正确性自检：pypinyin 逐题核对正确答案 + 检查干扰项是否"够像"
pip install pypinyin
python tools/check-pinyin.py

# 3) 功能自检：用 jsdom 真的把流程点一遍（需先起本地服务）
npm i jsdom
python -m http.server 5183     # 另开一个窗口
node tools/smoke-test.js

# 4) 图像过目（可选）：把 29 张讲解图 / 全身像导出成 PNG 亲眼看一遍
npm i sharp
node tools/render-illus.js
node tools/render-avatar.js    # 输出在 tools/_preview/
```

`smoke-test.js` 会覆盖 74 项断言，包括：首次进入选角色、插画风全身像渲染、选项乱序与答案重算、
六种题型逐一作答（含补韵母填空）、答错→图文讲解→举一反三闭环、语音两级降级、报告页、
衣柜与全身换装（13 个槽位独立）、彩蛋开箱特效、激活码校验、免费额度与完整版额度、刷新后进度保留。

**改完内容后跑一遍这几条，能拦住 95% 的低级错误。**

## 六、语音和音效是怎么工作的

语音两级降级，**永远不花钱**：

1. **优先**播放 `audio/q/<id>.mp3`（提前用 edge-tts 生成的真人级语音，微信里稳定）
2. 如果音频文件缺失或加载失败 → 自动降级到浏览器内置的语音合成（`speechSynthesis`）
3. 浏览器也不支持 → 提示"这个浏览器不支持朗读"，其余功能照常用

音效（答对的叮咚 / 答错低鸣 / 点按 / 开蛋）用 **WebAudio 现场合成**，
没有任何音频文件，也不需要网络。首次发声需要一次用户点击（微信 / 浏览器都会放行）。

## 七、教学逻辑说明

### 抽题优先级（全在本地算，不调 AI）

```
第 1 优先：答错过的题（且对应知识点还没掌握）—— 错得越多越靠前
第 2 优先：从没做过的题
第 3 优先：已做过的复习题 —— 连续答对次数越少越靠前
        并且尽量不让连续两道题撞同一个知识点
```

### 答错后的闭环

```
答错 → 立刻弹出该知识点的图文讲解（可听语音）
     → 关闭讲解，插入一道「举一反三」同类题
     → 原题排到本轮最后，重新测一次
     → 重测答对额外 +15 分
```

### 积分规则

| 行为 | 积分 |
|:---|:---|
| 答对 1 题 | +10 |
| 连续答对 5 题 | 额外 +20 |
| 掌握 1 个知识点 | +50 |
| 看完讲解后重测答对 | 额外 +15 |

### 「掌握」怎么判定

某个知识点下的题，**至少答过 4 道，且其中至少 3 道已连续答对 2 次** → 判定为掌握。

### 彩蛋触发

- 累计掌握的知识点数每达到 **3 的倍数** 触发一次
- 连续练习天数每达到 **3 的倍数** 触发一次
- 彩蛋从「还没有的装扮」里随机掉一件，全收集齐了则改送 +100 积分

## 八、常见问题

**Q：点「听一听」没声音？**
A：① 先确认是在 http/https 下打开（双击本地文件不行）；② 手机音量/静音键；③ 检查 `audio/q/` 里有没有对应的 mp3。

**Q：微信里打开链接，提示"非官方网页"或加载慢？**
A：这是国内访问 Vercel 的常见现象，功能不受影响。要彻底解决就换国内静态托管（腾讯云 COS/CDN）。

**Q：想加"看图片选注音""连线题"怎么办？**
A：`js/app.js` 的 `renderQuestion()` 是按题型渲染的入口，加新题型时在这里分支即可；
数据结构上给 `QUESTIONS` 加一个 `type` 字段区分。现有架构已经留好了位置。

**Q：数据存在哪？换手机还在吗？**
A：目前存在浏览器 localStorage 里，**换设备/清缓存会丢**。
如果要跨设备同步，需要接后端（微信登录 + 云数据库），这是 V2 的事。

**Q：免费版和完整版的区别？**
A：免费版每天 `freeDailyLimit`（默认 10）道题；完整版不限次数。改这个数值就能调整策略。
